# Machinevision-Industrielle
Je partage MachineVision, un prototype de reconnaissance de machines industrielles à partir d’une photo.Le projet combine React et Vite pour l’interface, Spring Boot pour l’API, Python avec TensorFlow/Keras pour la prédiction, et MySQL pour les équipements et l’historique. Il permet d’identifier une catégorie des machines puis de retrouver les docs
